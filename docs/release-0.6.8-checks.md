## 审查修复

- 保存当前学期课表后立即派发集成，不被后续校历、通知请求延迟；历史学期仍不能覆盖当前外部课表。
- 启动阶段也受独立看门狗与代次所有权保护；启动完成与超时互斥，旧回调不能释放新任务。
- 心跳 RPC 与网络请求不阻塞看门狗或清理；终止后断开连接、回收渲染器并保留回执 fencing。
- 显式处理后台渲染进程退出，避免默认行为终止小爱宿主。
- 连续更新保留最新待处理版本，取消管理会清除待处理更新。
- Android 17 小组件测试改用真正的 AppWidgetHostView，修复普通容器不能设置集合适配器造成的测试失败。
- 独立代码复核确认上述阻塞问题已解决。
