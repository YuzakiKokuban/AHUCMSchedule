# 课表体验与状态管理设计（第 1–5 项）

日期：2026-10-24

## 目标与范围

实现用户选定的五项改进：同步后知道课表具体变化、快速查看今日及下一节课、同步失败时知道如何恢复、抽离登录与同步状态管理、查看已缓存的历史学期。本轮修改 Android / Windows 共用的 Kotlin 核心及 Compose 界面；鸿蒙独立原型另行适配。

沿用现有 miuix 主题、账号隔离和完整 XLS 校验，不增加依赖，不改学校消息已读状态。成功落盘后才更新界面及同步变化；失败保留旧课表。后台通知与桌面小组件不在本轮范围内。

## 方案取舍

建议在现有课表页增加今日视图和变化入口，复用共享界面。增加独立底部导航页会挤占现有三个入口；默认改为今日视图会改变已有使用习惯，因此本轮默认保留周视图。

变化通过相邻官方快照比较得到，不从调课通知推断。通知可能缺失或重复，不能作为最终课程安排的来源。仅有两个快照时不能可靠判断所有调课关系，宁可明确展示新增和移除，也不猜测课程移动。

错误在产生处分类，向界面传递类型与安全提示，不通过匹配异常文案推断原因。

状态管理采用两端共用的控制器与 StateFlow，平台只提供文件选择、账号存储、日历等能力。不新增 Android 专属 ViewModel 依赖到共享界面，也不在本轮重写已存在的平台服务。

## 1. 同步变化

- 仅比较同账号、同学期的前后两份官方快照；首次同步、新学期或此前仅有文件导入时，提示已建立官方基线。
- 按一次课程安排计数，不把连续四节课统计成四门课。忽略列表排序与同步时间变化。
- 日期、节次及课程身份可明确对应时，展示教室、教师、课程类型、教学内容的前后变化；无法唯一对应的条目显示新增或移除，不声称一定是停课。
- 作息时间单独列出变化，避免只显示课程未变化。
- 成功同步后显示摘要及“查看变化”入口，详情展示日期、节次和前后值；无变化明确提示“课表无变化”。
- 同一次运行中，无变化的定时刷新不清掉最近一次有变化的结果；切换账号、学期或手动导入时清除该结果，避免展示错属账号的变化。本轮不增加持久化历史。

## 2. 今日课程与下一节

- 课表页提供“周课表 / 今日”切换，初始仍显示周课表。
- 今日按上海日期及节次排序，列表显示课程名、时间、教室及教师，可打开完整详情。
- 非连续节次拆为独立时段；同时进行的课程全部保留。
- 突出正在上的课；无正在上课时，突出今日下一时段的课程。今日全部结束与今日无课分别提示。
- 缺少作息时仍展示日期和节次，提示同步作息，不推算正在上课或下一节。
- 前台更新时间及日期，覆盖跨午夜和周一切换；保持可注入时间以便确定性测试。

## 3. 可操作的失败提示

- 网络断开或超时：提示检查网络并重试。
- 明确的登录失效（登录页、401/403 等）：提示重新连接教务，提供登录入口。
- 学校服务异常：提示学校暂不可用、稍后重试，不误报密码错误。
- 学校页面、XLS、学期或作息结构不符合要求：提示数据校验失败、保留旧课表，可重试或打开教务核对。
- 本地保存失败：提示检查存储空间、重试，不误导用户重新登录。
- 未知错误：安全的通用提示，不暴露异常堆栈、账号、Cookie、请求正文或服务器返回原文。
- 通知同步失败与课表同步结果分别展示；取消操作继续传播取消信号，不变成失败提示。
- 错误提示只有存在旧课表时才说“已保留上次课表”；首次同步失败不暗示已有缓存。

## 4. 登录与同步状态管理

- 将账号恢复、登录、同步调度、文件导入及相关反馈从 App.kt 移入共享控制器；页面导航和弹窗等纯界面状态保留在 Compose。
- 通过明确的操作状态表示恢复、登录、同步及导入，统一安排互斥操作；定时同步不重复排队，手动操作不与账号切换交错写入。
- 异步任务绑定启动时的账号与会话；旧任务的完成结果不能覆盖新账号的界面或触发新账号的日历、小爱同步。
- 维持每五分钟前台同步、返回前台检查、成功落盘后同步外部集成的行为；界面重建不产生重复同步循环。
- 控制器有明确的创建、取消和销毁归属，Android 的界面重建与桌面窗口关闭均按生命周期处理；沿用 SchoolClient 的会话串行机制。
- 取消不会显示成失败，任何结束路径都恢复正确的可操作状态。用可控时钟和阻塞测试替身验证并发及生命周期。

## 5. 历史学期切换

- 仓库暴露当前账号的已缓存学期列表及指定学期快照，课表页以学期选择器切换；没有缓存的学期不提供入口。
- 区分“正在查看的学期”和“学校最新同步学期”。查看历史学期时，自动及手动同步仍获取学校当前学期，不强制跳走当前历史页面。
- 切换到历史学期时定位到该学期第一教学周；切回覆盖今天的学期时定位本周；“本周”按钮仅在今天属于所选学期时生效，其余情况提供“首周”。
- 今日视图始终属于所选学期，历史学期明确提示所选学期不包含今天，并可切换周视图查看。
- 学期选择在本次运行中保留，切换账号后重新选择该账号默认学期；不修改旧缓存的活动学期含义。
- 历史浏览不会覆盖日历或小爱课表。查看历史学期时隐藏手动外部同步入口，自动集成只消费成功获取的学校当前学期快照。
- 变化结果绑定账号与学期，显示时注明归属；历史学期页面不展示当前学期的变化摘要。

## 实现边界与验证

核心增加独立快照比较及今日时段计算模块和学期查询接口；共享界面增加状态控制器、今日课程、变化详情及学期选择组件，避免继续把逻辑堆入 App.kt。先完成控制器抽离并验证现有行为，再接入三项体验功能和学期选择。

先增加失败测试再实现。覆盖首次同步、跨学期、文件基线、无变化、重复和并行课程、教室调整、无法唯一对应的变动、作息变化、跨午夜、缺失作息、课程起止边界，以及各错误类型和失败不覆盖旧缓存。

另覆盖同步中返回前台、重复点击同步、文件返回与同步交错、同步中切换账号、取消后恢复、界面重建，以及历史学期离线读取、同步不改变浏览学期、账号学期隔离和历史浏览不触发外部覆盖。

运行核心测试、Compose 桌面测试、Android 编译和现有 JavaScript 回归测试；真机未验证的部分明确记录，不声称已验收。
