# 安卓桌面今日课表小组件

用户已明确选择安卓手机/平板主屏幕小组件。显示今天日期、课程时间、名称、教室和正在上课/下一节状态；提供无课、未缓存、作息未同步及文件导入来源提示。点击打开应用。沿用玉绿品牌、系统深浅色和 Android 12+ 动态配色。

采用系统 RemoteViews 集合列表，支持纵横调整尺寸与课程滚动；Android 12+ 使用 RemoteCollectionItems，Android 8–11 使用受 BIND_REMOTEVIEWS 保护的 RemoteViewsService。无需新增依赖、日历权限或精确闹钟权限。应用内提供「添加桌面小组件」入口，由系统/启动器确认添加。

数据只读取当前账号的本地缓存，不登录、不读取密码、不后台访问学校。根据上海日期选择覆盖今天的课表，优先学校当前学期，忽略应用里用于浏览的历史学期选择。连续节次合并，非连续节次拆开；状态按真实作息区间判断，课间不误标为正在上课。无作息时只展示节次，不猜时间。

成功同步、手动导入、账号切换和前台恢复触发重读；系统周期更新、日期/时间变化、重启/升级、调整小组件尺寸也会更新。用非精确、非唤醒闹钟请求下一次课程边界或午夜刷新，系统可延迟，不承诺精确到分钟。显示数据来源与更新时间；不使用常驻服务。

旧账号的异步结果不得覆盖新账号小组件。更新提交与账号切换在进程内串行检查；旧系统集合工厂提供行数据前再次校验账号。锁定状态不读取凭据保护目录。课程文本和列表长度设显示上限，异常大数据以打开应用查看更多提示，避免 Binder 超限。

验证：核心匿名用例覆盖当日/跨日、历史选择隔离、无课/无缓存、缺作息、并行课、非连续节次和课间状态；Android 仪器用例检查 RemoteViews 实际膨胀、空状态、主题/尺寸和账号保护。构建验证不能替代真实启动器添加与自动刷新验收。

参考：Android 官方 [集合小组件](https://developer.android.com/develop/ui/views/appwidgets/collections)、[更新调度](https://developer.android.com/develop/ui/views/appwidgets/advanced)。
